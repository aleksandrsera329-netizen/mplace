# Demo video script — 5–7 minutes (buyer sale)

**Record from:** https://mplace-vu4o.onrender.com  
**Language:** English on screen (optional RU voiceover)  
**Do not show:** passwords on screen, `docs/PRIVATE_DEMO.md`, API keys  
**Private logins:** only after cutting to “scheduled demo” segment (or blur password field)

---

## Shot list + spoken lines

### 0:00–0:40 — Home / positioning
**Show:** homepage hero + catalog grid  
**Say:**  
“This is Mplace Energy — a multi-vendor B2B marketplace for oil and gas procurement.  
Buyers browse industrial equipment from verified suppliers, build order lists, and run RFQs.  
You’re looking at a live always-on demo.”

**Click:** scroll products briefly; point to “Request Private Demo”.

---

### 0:40–2:00 — Catalog, search, product
**Show:** sidebar filters, search, open 1–2 product cards  
**Say:**  
“The public catalog is English-first: categories, suppliers, stock, and USD pricing.  
Twenty-plus demo SKUs across drilling, valves, PPE, instruments and chemicals.  
Buyers can filter, open a product, and add lines to an order list.”

**Actions:** type “valve” or “PDC”; open product; Add to order; open cart drawer.

---

### 2:00–3:00 — Order / request
**Show:** cart drawer → cart.html checkout flow (demo payment ok)  
**Say:**  
“From the cart the buyer submits a procurement request.  
This is the standard buy path — not just a brochure site.  
For competitive sourcing, we also support RFQ.”

---

### 3:00–4:30 — RFQ path
**Show:** rfq-create → (private) list of RFQs / offer if logged in as merchant  
**Say:**  
“RFQ: the buyer publishes a request with line items and deadline.  
Matched suppliers receive it; they submit offers; the buyer can award a winner.  
In the seeded data you already have open and awarded RFQ examples for a closed-door walkthrough.”

**Note for recording:** for full award UI use private buyer + merchant logins (off-camera password).

---

### 4:30–5:30 — Seller cabinet
**Show:** merchant products / orders (private login)  
**Say:**  
“The seller desk covers products, stock and incoming orders —  
what a real supplier needs day to day on the platform.”

---

### 5:30–6:30 — Admin
**Show:** admin dashboard (private super-admin)  
**Say:**  
“Platform admin: shops, orders, payouts and support tickets.  
This is the operator console a marketplace owner runs after go-live.”

---

### 6:30–7:00 — Close / value
**Show:** homepage + request-demo page  
**Say:**  
“What you’re buying is a working B2B foundation — catalog, RFQ, seller and admin —  
that can save six to twelve months of rebuild.  
Public demo link is on screen; request a private demo for full credentials under NDA.  
Contact in the sales one-pager.”

**End card (text on screen 5s):**
```
Mplace Energy — Oil & Gas B2B Marketplace
Demo: https://mplace-vu4o.onrender.com
Private demo: /request-demo.html
Contact: aleksandrsera329@gmail.com
```
