# Product demo video — 7 minute script / shot list

A finished video still requires a screen recording from the deployed demo environment.

1. **0:00–0:40 — Opening**
   - Landing page
   - Explain B2B marketplace positioning
2. **0:40–1:40 — Buyer**
   - Catalog
   - Search
   - Product
   - Cart
   - Checkout
3. **1:40–2:50 — Merchant**
   - Merchant dashboard
   - Product management
   - Incoming order
   - RFQ offer
4. **2:50–4:00 — RFQ**
   - Buyer creates RFQ
   - Merchant responds
   - Buyer awards offer
   - Order is generated
5. **4:00–5:00 — Payments**
   - PaymentIntent
   - Stripe test event
   - Webhook processing
   - Ledger/payout view
6. **5:00–6:00 — Security**
   - Tenant switch / isolated tenant
   - MFA
   - Admin
   - KYC/media ACL
7. **6:00–7:00 — Architecture**
   - Show architecture diagram
   - PostgreSQL / Redis / Meili / BullMQ / Stripe
   - Close with pilot/acquisition positioning
