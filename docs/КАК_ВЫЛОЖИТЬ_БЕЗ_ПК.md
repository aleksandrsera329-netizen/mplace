# Как выложить Mplace в интернет (без вашего ПК)

Сайт будет жить на **Render.com** — бесплатно. Ваш компьютер можно выключать.

## Шаги (около 10 минут)

### 1. Зарегистрируйтесь
Откройте: https://render.com/  
Нажмите **Get Started** → войдите через **GitHub**  
(аккаунт GitHub: `aleksandrsera329-netizen`)

### 2. Подключите проект
Откройте: https://dashboard.render.com/select-repo?type=blueprint  

Или вручную:
1. **New +** → **Blueprint**
2. Подключите репозиторий **mplace**
3. Render найдёт файл `render.yaml`
4. Нажмите **Apply** / **Deploy**

### 3. Подождите сборку
5–15 минут. Статус станет **Live** (зелёный).

### 4. Скопируйте ссылку
На карточке сервиса `mplace` будет адрес вида:

`https://mplace-xxxx.onrender.com`

**Эту ссылку и отправляйте заказчику.**

## Важно (бесплатный план)

- После **~15 минут** без визитов сайт «засыпает».
- Первый заход после сна: **30–60 секунд** — это нормально, подождите.
- Данные демо (товары/заказы) могут сброситься при обновлении сервиса.
