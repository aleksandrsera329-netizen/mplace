## Epic 1. Роли, аутентификация и безопасность

**Цель:** полноценная система ролей и безопасности уровня enterprise.

### US-1.1 — Регистрация, вход, 2FA

| | |
|--|--|
| **As a** | пользователь |
| **I want** | регистрироваться и входить с email/телефоном + 2FA |
| **So that** | мой аккаунт защищён |

**Acceptance Criteria**

- [ ] Регистрация по email и телефону  
- [ ] Подтверждение email / SMS  
- [ ] Вход с 2FA (TOTP или SMS)  
- [ ] Восстановление пароля  
- [ ] Блокировка после 5 неудачных попыток  

**Tasks**

- [ ] Модель User + роли: Guest, Buyer, Vendor, Admin, SuperAdmin  
- [ ] JWT + refresh tokens  
- [ ] 2FA (Google Authenticator / SMS)  
- [ ] Rate limiting на auth endpoints  
- [ ] Аудит-лог всех входов  

### US-1.2 — KYC продавцов

| | |
|--|--|
| **As a** | Админ |
| **I want** | верифицировать продавцов (KYC) |
| **So that** | на платформе только проверенные поставщики |

**Tasks**

- [ ] Загрузка документов (паспорт, ИНН, устав, сертификаты)  
- [ ] Статусы: Pending → Approved → Rejected
